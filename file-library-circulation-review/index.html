文件库支持传阅

产品经理：杨佳桧评审摘要 · 2026.11.13
01

需求背景

支持从文件库直接传阅公文，设置对象的可见内容与字段权限，统一记录已阅情况；常用配置按用户与模板复用。

办理中可传阅已办结可传阅已归档可传阅
02

核心操作链路

1发起传阅

点击文件库右侧按钮“传阅”

2配置范围

选对象，设置传阅内容及字段权限

3确认发送

操作成功后保存本次设置

4接收查看

传阅对象按权限查看传阅详情页

5记录已阅

点击“已阅知”同步记录

03

重点关注的逻辑设计

01权限分层

能否发起→能否访问→能看什么

文件库操作权限决定能否发起；模板高级设置控制详情页访问；本次传阅配置决定内容可见范围。

访问权限模板开启“仅允许流程内的用户及传阅对象查看公文详情页”时，其他人不可访问。

传阅详情页默认权限流程内取本人最近参与的办理 / 抄送节点权限；流程外取发起节点权限。

传阅详情页自定义权限对传阅对象统一生效，可自定义传阅内容显示范围及字段可见权限。

02传阅设置

选择传阅对象，设置传阅信息显示（数据详情、稿纸、流程、评论、数据日志），并选择详情字段的默认或自定义权限。

03设置保存与复用

按 uid + 公文模板id，将当前用户的传阅设置保存至服务端，供同模板公文复用。只保存信息显示与字段权限，传阅对象每次重选。

传阅成功后覆盖上次设置；取消、关闭、校验失败或传阅失败均不更新，后续回填不改变已发出的传阅配置。

字段权限按字段 ID 保存：改名、排序保留，删除忽略，新增默认不勾选；无有效可见字段时重新配置。

04记录与历史兼容

每次成功传阅均留记录。同一公文再次传给同一用户，复用链接及待阅数据、重置未读、以最新权限覆盖。

点击“已阅知”同步该用户相关历史记录；再次传阅前保留原内容权限。传阅不改变公文办理或归档状态。

二、需求详述

1. 需求背景

文件库需要支持直接将公文传阅给指定对象，并在发起时设置对方可查看的信息范围。详情字段支持按默认权限或自定义权限显示，文件库发起的传阅统一纳入该公文的传阅记录，便于跟踪已阅情况。

本次以 PC 端文件库单条数据右侧的“传阅”操作为范围，参考节点的传阅信息显示设置；不扩展批量传阅或移动端文件库发起入口。

2. 功能入口

项目 内容
所属模块 应用前台 > 文件库
操作入口 列表单条数据右侧操作栏新增“传阅”按钮
点击效果 打开当前公文的“传阅设置”弹窗
关联权限 文件库操作权限 > 右侧按钮中增加“传阅”，与“传阅记录”独立控制

3. 功能说明

3.1 文件库操作权限新增“传阅”右侧按钮

在“文件库操作权限 > 右侧按钮”分组增加“传阅”复选项，控制文件库单条数据右侧的“传阅”按钮显示。

  • “传阅”位于“跳转”按钮后，“传阅记录”按钮前
  • 勾选并保存后，该角色在其文件库数据权限范围内可使用右侧“传阅”按钮；未勾选时不显示该按钮，不能从文件库发起传阅。
  • “传阅”纳入文件库操作权限既有“选择全部”的联动范围，选中、取消及回显沿用现有规则。

默认值与历史权限处理

角色场景 “传阅”默认状态及处理规则
已有角色，包括已有超管角色 新增“传阅”权限默认未选中，其他已有权限保留原勾选状态
已有角色原“选择全部”已选中 “传阅”仍默认未选中，“选择全部”同步取消勾选，原有各权限选中状态保留
新建的非超管角色 “传阅”默认未选中
新建的超管角色，包括新开通单位的超管角色 沿用默认所有权限全选的规则，包含“传阅”

允许传阅的数据状态

具备“传阅”操作权限及当前公文数据访问权限时，办理中、已办结、已归档的数据均允许传阅。传阅不会改变原有办理或归档状态。

3.2 文件库传阅设置

在文件库点击单条数据右侧的“传阅”按钮，打开传阅设置弹窗，确认操作后发起传阅。

3.2.1 弹窗及提交校验

弹窗标题为“传阅设置”，包含以下内容：

设置项 交互与规则
传阅对象 必填。点击“选择”打开对象选择弹窗，从公文模板绑定架构下选人，回显选择结果，支持调整
传阅信息显示 必填。可设置数据详情、稿纸、流程、评论、数据日志；数据详情下包含详情、正文、附件
数据详情字段权限 勾选“详情”时显示，可单选“默认权限”或“自定义权限”；未勾选“详情”时不生效
取消 / 关闭 关闭弹窗，不发起传阅、不生成传阅记录
确定 校验必填设置，通过后按本次选择发起传阅；成功关闭弹窗，显示toast提示“传阅成功”

用户首次打开传阅设置弹窗（当前 uid + 公文模板id 下无已保存的传阅设置，详见 3.2.5）时，默认选中全部传阅信息显示项，数据详情字段权限默认选择“默认权限”。

3.2.2 传阅对象

在当前公文数据所属收发文模板绑定的组织架构下选择成员或部门。

  • 选人弹窗内左侧展示组织架构下的部门，右侧展示部门下的人员，支持部门与人员混选。
  • 支持检索用户名称；选中部门时，将通知发送时该部门下的全部人员作为传阅对象。
  • 部门与人员交叉选择时，最终接收人员去重；通知执行后新增的部门人员不补入本次传阅。
  • 传阅对象为空时，点击“确定”不提交，提示“请选择传阅对象”。
  • 传阅对象确认后返回“传阅设置”弹窗；选择对象本身不立即发送传阅。

3.2.3 传阅信息显示

一级选项 二级选项 控制范围
数据详情 详情 控制除正文、附件外的字段详情是否显示；具体可见字段由本次字段权限决定
数据详情 正文 控制正文内容是否显示
数据详情 附件 控制附件内容是否显示
稿纸 — 控制稿纸是否显示
流程 — 控制流程是否显示
评论 — 控制评论是否显示
数据日志 — 控制数据日志是否显示
  • 勾选“数据详情”时，其下至少保留一个选中项。取消最后一个二级选中项时，保留该项选中并提示“请至少选择一个”。
  • pc端/移动端均按本次的传阅信息显示设置控制传阅详情页内对应标签页或区域的显隐，未勾选的内容不向本次传阅对象展示。
  • 注意，节点操作传阅时，限制了传阅对象的可见权限必须小于等于传阅发起人。文件库操作传阅无此限制，默认传阅发起人对全部传阅显示信息都有可见权限。

3.2.4 数据详情字段权限

该设置仅在勾选“数据详情 > 详情”时显示，与“详情”是否显示共同决定本次传阅的字段可见范围。

权限方式 功能规则
默认权限 流程内用户取最新一个节点的字段权限（“最新一个节点”指传阅对象本人在流程内最近一个参与的办理或抄送节点）；流程外用户取发起节点的字段权限
自定义权限 发起传阅时配置本次传阅的详情字段可见范围，对本次全部传阅对象生效
  • 默认权限按每位传阅对象的身份分别判断，“自定义权限”对全部传阅对象统一生效。
  • 选择“自定义权限”后，显示设置字段权限的入口，点击后在弹窗内设置字段可见权限，初次设置时默认全部字段可见。至少要选择一个可见字段，否则禁止保存。设置完成后，自定义权限设置项下方回显本次设置的字段可见范围。包含两种回显规则：
    • 设置了全部字段可见时，字段可见范围回显：全部字段可见
    • 设置了部分字段可见时，字段可见范围回显：已设置 n/m 个字段可见

3.2.5 传阅设置的服务端保存与回填

按 uid + 公文模板id 在服务端保存一份最近一次成功传阅的设置。同一用户对同一模板下的不同公文发起传阅时复用该设置，跨设备、跨浏览器保持一致；不同用户、不同公文模板分别保存。

保存范围 保存内容
传阅信息显示设置 详情、正文、附件、稿纸、流程、评论、数据日志的勾选状态
详情页字段权限 “默认权限”或“自定义权限”的选择；自定义权限下按字段 ID 保存各字段可见设置，可用可见字段 ID 集合表达

仅保存上述两类配置，不保存传阅对象，每次打开弹窗，传阅对象均需重新选择；默认权限仍按本次公文及接收对象的适用规则确定。

存储与读取时机：

  1. 打开“传阅设置”弹窗，按当前用户 uid + 当前公文所属模板id 读取服务端配置，并按当前公文使用的字段结构适配后回填。
  2. 点击“确定”且校验通过，按本次最终确认的配置发起传阅；系统确认传阅成功后，新增或覆盖该用户在该模板下保存的设置。
  3. 仅修改勾选项、取消、关闭、校验未通过或传阅失败时，不更新已保存配置。

保存的设置仅用于下次弹窗回填，后续更新不修改已发起传阅的配置。

自定义字段权限的变化适配：

自定义字段权限使用字段 ID 匹配，保存具体的可见字段 ID 集合。

字段变化 回填规则
修改名称或调整顺序，字段 ID 不变 保留原勾选状态，按当前名称及顺序展示
删除字段 忽略该字段的已保存配置，不再展示；下次传阅成功后保存有效配置，清理失效字段 ID
新增字段 默认不勾选，即不可见，由用户主动选择

注意：若字段变化导致自定义权限无有效可见字段，回显“已设置 0/m 个字段可见”，点击确定阻止提交，并提示“请至少设置1个可见字段”。

3.3 传阅详情页查看

  • 文件库发起的传阅详情页仍受当前公文所属模板高级设置中的“仅允许流程内的用户及传阅对象查看公文详情页”控制。
  • 文件库发起的传阅沿用现有节点传阅规则：同一公文多次传阅给同一用户时，不重复新增待阅数据，仅将该用户的阅读状态重置为未读，并以最新一次传阅设置覆盖其传阅详情页权限。

3.4 传阅记录及历史数据处理

3.4.1 文件库传阅需纳入传阅记录

文件库每次成功发起传阅，都必须进入该公文现有的“传阅记录”，与详情页发起的传阅统一展示；取消或未成功发起的操作不生成成功传阅记录。

记录复用既有结构，包含传阅发起人、传阅时间、传阅时的文件标题、传阅对象及已阅数量。

  • 按既有传阅时间升序展示，支持在现有弹窗中刷新查看。
  • 传阅对象点击“已阅知”后，同步该用户作为传阅对象的该公文全部历史传阅记录中的已阅状态和数量。

3.4.2 历史数据兼容

  • 新发起的文件库传阅采用本需求的显示设置及字段权限规则。
  • 同一公文再次传阅后，继续使用原传阅详情页链接，按接收对象最新生效的传阅权限展示。历史已发送传阅在再次传阅前保留原传阅内容权限；再次传阅后，按最新一次传阅设置覆盖对应接收对象的传阅权限。
