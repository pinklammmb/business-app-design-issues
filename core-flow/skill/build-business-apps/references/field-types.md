# 字段组件类型（field-types）

> 出处：《第三方 AI 建表页面接入协议》第 6.1 节。`compt` 的取值**以创建页 `supportFieldMap` 为准**；本表是当前约定的白名单。

## 1. 组件类型白名单

| `compt`         | 适用字段            |
| --------------- | --------------- |
| `editinput`     | 单行文本、姓名、学号、联系电话 |
| `textarea`      | 长文本、备注、申请理由     |
| `select`        | 单选下拉            |
| `multiple`      | 多选              |
| `radio`         | 单选按钮            |
| `checkbox`      | 多选框             |
| `date`          | 日期              |
| `datetime`      | 日期时间            |
| `datetimerange` | 日期时间范围          |
| `number`        | 数字              |
| `rate`          | 评分              |
| `upload`        | 附件或文件           |
| `belonger`      | 所属人             |
| `relateddata`   | 关联数据            |
| `detailcombox`  | 子表单 / 明细表       |

## 2. 从字段语义到类型的映射参考

业务系统建设方案中字段类型未明确标注时，按语义就近映射，并**在回显中标注推断依据**：

| 字段语义线索 | 建议 `compt` |
| --- | --- |
| 姓名 / 学号 / 工号 / 标题 / 编号 / 电话 / 邮箱 | `editinput` |
| 备注 / 说明 / 理由 / 描述 / 意见 | `textarea` |
| 类型 / 类别 / 状态 / 等级（**枚举取值唯一**） | `select` |
| 标签 / 涉及范围（**可多值**） | `multiple` 或 `checkbox`（**选项数量少且需全部可见时用 `radio` / `checkbox`**） |
| 是否 / 单选项（2–5 个选项，需全部可见） | `radio` |
| 日期（不含时间） | `date` |
| 具体到时分秒的时点 | `datetime` |
| 起止时间 / 时间段 | `datetimerange` |
| 金额 / 数量 / 天数 / 人数 | `number` |
| 满意度 / 评价打分 | `rate` |
| 附件 / 凭证 / 图片 / 文件 | `upload` |
| 负责人 / 所属人 | `belonger` |
| 引用其他表的数据 | `relateddata` |
| 明细行 / 子表单（一张表内嵌多行） | `detailcombox` |

## 3. 降级规则

1. **创建页行为**：`compt` 无法识别时**自动降级为 `editinput`**——字段仍会生成，但**字段能力丢失**（如选项、日期选择、附件上传全部退化为单行文本）。
2. **本 skill 行为**：
   - 优先使用白名单内的类型，**不主动降级**；
   - 确实无法映射时，**显式降级为 `editinput` 并在回显中标注**「⚠️ 字段 X 类型未在白名单内，已降级为单行文本，原能力可能丢失」；
   - **不得自造类型**（如 `multiselect`、`datepicker` 等未约定写法）。
3. **新增类型前**：若业务确需白名单外的类型，**先与创建页维护方确认映射关系**，确认后再补充白名单；未确认前一律按白名单内类型承载。

## 4. 与创建页同步

- `supportFieldMap` 是创建页侧的真实映射表；本表与之**可能随版本漂移**。
- 每次生成前如无法确认 `supportFieldMap` 的当前内容，**按本表白名单生成**，并在回显中提示「以创建页当前 `supportFieldMap` 为准」。
- 若发现本表与创建页实际支持的类型不一致，**以创建页为准并回报差异**，由协议文档与本文件同步更新。
