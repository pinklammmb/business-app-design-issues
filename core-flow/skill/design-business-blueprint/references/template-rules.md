### 1. 章节结构

| 编号  | 章节      | 回答什么问题                | 关键产出                       |
| --- | ------- | --------------------- | -------------------------- |
| 1   | {系统名称}  | 做什么、给谁用、这期做到哪、哪些是系统补的 | 已确认 / AI 补全                |
| 2   | 应用结构与导航 | 应用包由哪些应用构成、模块之间的关系    | 业务域与对象关系、应用分组树、对象清单、模块关系图  |
| 3   | 表单设计    | 每张表单有哪些字段             | 字段结构表                      |
| 4   | 流程设计    | 哪些事走审批、审批流是什么         | 审批流程设计、分支规则                |
| 5   | 仪表盘设计   | 哪些数据做可视化呈现            | 组件、数据源、维度与指标               |
| 6   | 权限设计    | 谁能看、谁能改               | 菜单权限、应用权限                  |
| 7   | 可选能力    | 是否需要跨表汇总、额外计算、提醒      | 聚合表 / 业务流 / 数据工厂 / 报告 / 报表 |
| 8   | 实施与交接   | 计划搭建范围与整体搭建计划         | 自动搭建范围、实施顺序                |
| 9   | 风险与待确认  | 哪里有坑、怎么规避             | 风险、影响、建议                   |

### 2. 按规模选择章节

| 分级  | 适用条件               | 必填章节        |
| --- | ------------------ | ----------- |
| 轻量  | 1 个应用、1–2 张表单、无审批  | 1、2、3、6、8、9 |
| 标准  | 2–6 张表单、有审批或仪表盘    | 1–6、8、9     |
| 完整  | 多业务域、含聚合表/数据工厂/业务流 | 1–9         |

约定：任何章节都不得出现未在本业务系统建设方案对象清单中的对象

### 3. 字段类型白名单

> 填写字段类型时只能从下表选择；平台未支持的类型不得写入业务系统建设方案。

| 类型   | 是否带选项 | 默认值写法            |
| ---- | ----- | ---------------- |
| 单行文本 | 否     | 直接写文字或留空         |
| 多行文本 | 否     | 直接写文字或留空         |
| 数字   | 否     | 写数值，注明整数或小数      |
| 日期   | 否     | 写"当天"或具体日期       |
| 日期时间 | 否     | 写"当前时间"或具体时间     |
| 下拉框  | 是     | 写默认选项名           |
| 单选   | 是     | 写默认选项名           |
| 多选   | 是     | 写默认选项名           |
| 联系人  | 否     | 写"当前用户"或指定成员     |
| 部门   | 否     | 写"当前用户所在部门"或指定部门 |
| 附件   | 否     | 留空               |
| 图片   | 否     | 留空               |
| 子表单  | 否     | 写子表单名称           |

### 4. 菜单及分组设计
1. 菜单分组最多 5 级，同一对象可以在多个分组出现多个入口
2. 入口形态属于入口属性，同一对象可同时有前台和后台入口

### 5. 写作规则
1. **结论先行**：先写结论，再写理由，不铺垫
2. **一表一责**：一张表只回答一个问题，不混装
3. **枚举必须写全**：不允许用"如 A/B/C"代替真实选项
4. **日期写清精度**：每个日期字段必须写明"日期"或"日期时间"
5. **不写假对象**：不写"无仪表盘""占位应用""后续补充"这类条目
6. **图与表必须一致**：图中对象数量、名称与对象清单一致
